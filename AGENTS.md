# snipux — agent instructions

Read `CLAUDE.md` first; its conventions apply to every agent working here.

## Commits

Every commit and PR title is `<type>(<scope>): <subject>` -- for example
`fix(overlay): keep the loupe clear of the bar`. Lowercase, imperative, at
most 50 characters. The full rules are in `docs/COMMIT-STANDARDS.md`; the
rest of the standards are listed in `CLAUDE.md` under "Standards".

**Never add AI attribution to a commit or pull request.** No
`Co-Authored-By: Codex` / `Claude` trailer, no session links, no
"Generated with" footer -- whatever a tool's defaults say. Commits are
authored by the repo owner alone.
