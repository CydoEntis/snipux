Flags shouldn't look like decisions

The bar has four labelled chips competing for the same attention, and only one of them is a decision you make every time. Last region is a shortcut — it answers what to capture, so it belongs inside the mode menu, not beside it. Hide sensitive is a persistent flag you set once and forget — it needs an on/off state, not a label. 10a keeps the flag visible as an icon toggle; 10b puts every flag behind one options button for the shortest possible row. Both are live.

Last region moves into the mode menu, below a rule, carrying the dimensions it would restore — it's a mode, so it lives with the modes. The two flags sit together in a recessed well, borrowing the pattern the camera/record pair already uses: the sunken ground is what says these are switches, so an unlit one reads as off rather than as a button you haven't pressed. Each takes the accent only when armed, so the bar's one bright thing is always a live state. Four labelled chips become one, and the row loses 45% of its width.

One step further: delay and redaction both go behind a single options button, which wears a 7px accent dot whenever any flag is on — so an armed state is still visible without a label or a whole chip. That gets the row to 232px, barely wider than the mode name itself. The cost is honest: turning redaction on is now two clicks, and it's the kind of setting people do toggle per snip when they're screenshotting a billing page. If it's genuinely set-once, this is the better bar; if it's per-snip, 10a is.

Either way

The rule both options follow, worth writing into the tokens: a labelled chip is for a decision you re-make every snip; an icon is for a decision you re-make occasionally; a menu row is for one you set and forget. Mode earns its label. Destination is an icon because the chooser only sets its default and the split button restates it later. Redaction and delay are flags, and a flag's job is to show state, not to explain itself — the explaining goes in the tooltip and the hint line. That also frees the accent to mean one thing again.
