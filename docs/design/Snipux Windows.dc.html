snipux · the two windows

Settings, and the review window

1a is Settings — a nav rail instead of one row floating in an empty dialog, with the shortcut recorder and its GNOME conflict check as the first thing you see. Press Record and hit a real combination; it detects conflicts live. 1b is the review window that opens after a snip: it shows the shot on a workspace with a real edge, says exactly where the file went, and its Annotate button reveals the same floating bar from the overlay rather than a second tool set — drawing here runs the same code path.
