Copy does not mean the same thing for a recording. A still goes on the clipboard as image data and pastes into anything. A video can only go on as a file reference — it pastes into a file manager, Slack, Discord or an upload field, and does nothing at all in an image editor or a text box. Offering an identical Copy for both silently fails half the time. So for recordings the label reads Copy file, and the toast says “File copied — paste into a chat or folder” rather than the stills toast's “Copied to clipboard”. Same key, honest wording.

The chooser picks which of these is the split button's face; the chevron always offers the other two, plus C / S / O as direct keys so a habit never costs a menu. All three always write the file first — Copy and Open included — because a capture that only exists on a clipboard is one Ctrl+C away from being gone, and every bug report starts with “where did it go”.
